# Refine

Refine is a free search builder for Android. Tick what you want, such as a file type, a website or a date range, and it writes the search shortcuts for Google, Bing or DuckDuckGo. It has no adverts, no accounts and no paid version, and your searches go to the search engine you chose and to nobody else.

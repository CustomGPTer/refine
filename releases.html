Version 1.0

First release

LatestReleased 16 November 2026

Added

  • A search builder with a box for every shortcut that still does something: search words, exact phrases, any-of words, words to leave out, file types, websites to search in or leave out, and dates.
  • 34 file types, with the 15 most used on show, the rest one tap away, and a box for any other.
  • Dates by one-tap buttons (past hour, day, week, month, year) or an exact From and To on a calendar.
  • Where the words appear: title, page text, web address, or links pointing to the page.
  • Kind of result: plain web links with no AI summary, Images, News, Videos, Short videos, Forums, Books, Shopping, Places, Maps, Scholar, Patents and Jobs.
  • Language and region: pages written in a language, pages from a country, searching as if from another country, and the language of the results page.
  • Fine tuning: exactly what I typed (Verbatim), no spelling correction, newest first, near-duplicate pages, untailored results and SafeSearch.
  • Image size, colour, kind, shape, usage rights and exact pixel size. Video length. Books by how much can be read.
  • Rarer ones: two words near each other, number ranges, sites like this one, quick lookups, news from one publication or place, and a box for anything typed as-is.
  • Google, Bing and DuckDuckGo. Boxes an engine does not understand are greyed out and left out of the search, and the app says which.
  • A “May not work” label on every hit-and-miss shortcut, and an explanation with an example behind every box.
  • The finished search shown as you build it, editable by hand, with a Copy button.
  • Paste a search to have the matching boxes ticked.
  • Site groups, with five starters, and presets, with 22 ready-made.
  • History kept on the phone, with run again, open in the boxes, and save as a preset.
  • Share and the highlight-text menu both send text into Refine. A shared web page becomes a search inside that site.
  • A home-screen widget and press-and-hold icon shortcuts for up to four starred presets.
  • A cheat sheet of every shortcut, which can be shared as text or saved as a PDF.
  • Results in your browser or inside Refine.
  • A backup file for presets, site groups, history and settings.
  • Wallpaper colours, light or dark.
  • A notice when a newer version is out.

Installing and updating

  • When you download, Chrome may warn that the file might be harmful. It shows this warning for app files that do not come from Google Play. Choose Download anyway.
  • Open the downloaded file. The first time, Android asks you to allow your browser or file manager to install apps. Allow it, then tap Install.
  • Google Play Protect may say it does not recognise the app, or block it, because Refine does not come from Google Play. Choose More details, then Install anyway.
  • To update, download the latest version and install it over the one you have. Your presets, site groups and history are kept.
  • Every version is signed with the same key, so Android accepts an update only if it comes from the same developer.
